# ⚡ EnergyPulse AI

## Smart Meter Consumption Profiler

EnergyPulse AI is an AI-powered energy analytics platform designed to analyze household electricity consumption patterns, predict future demand, detect anomalies, and identify peak load behavior.

## Features

* Electricity Consumption Analytics
* Peak Load Detection
* Consumption Forecasting
* Anomaly Detection
* Seasonal Trend Analysis
* Interactive Streamlit Dashboard

## Technologies

* Python
* Pandas
* NumPy
* Scikit-Learn
* Plotly
* Streamlit

## Machine Learning Models

* Random Forest Regressor
* Isolation Forest

## Dataset

UCI Household Power Consumption Dataset

## Deployment

Streamlit Cloud
